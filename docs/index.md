## Project Overview

**FormsApp** is a visual form builder application built with Vue 3 that allows users to:

- **Build forms** with 14 different field types via drag-free click interface
- **Preview forms** in real-time with validation
- **Save and manage** forms using browser localStorage
- **Export forms** as embeddable Web Components
- **View submissions** collected from form responses

## Feature Summary

### Form Builder

The main interface for designing forms:

- **Field Palette** - 14 field types (text, email, select, rating, slider, etc.)
- **Form Canvas** - Visual field ordering and selection
- **Properties Panel** - Field configuration (label, required, options)
- **Templates** - Pre-built forms for common use cases

### Form Preview

Live preview showing exactly how users will see the form:

- Real-time validation
- Error messages
- Field interactions

### Submissions

View and manage form responses:

- List all submissions
- View individual submission details
- Delete submissions

### Export Features

- **JSON Export** - Form schema for backup/sharing
- **Web Component** - Embeddable HTML/JS bundle
- **Import** - Load forms from JSON
